# Business Performance Dashboard | Excel Portfolio

**Microsoft Excel • KPI reporting • SUMIFS/COUNTIFS • Data modelling • Charts • Conditional formatting**

## Project overview

This project analyses a synthetic UK retail transaction dataset covering **2024 to August 2026**. The workbook demonstrates formula-driven business reporting, structured analysis sheets and an executive dashboard.

## Business questions

- How are revenue, gross profit and gross margin changing over time?
- Which products and categories contribute most to revenue?
- Which UK regions generate the strongest commercial performance?
- How many orders are completed versus cancelled?
- How can management track performance using a compact Excel dashboard?

## Workbook structure

- **Dashboard** — executive KPI cards and summary charts
- **Transactions** — transaction-level source data with formula-driven metrics
- **Monthly Summary** — monthly revenue, profit and order trends
- **Product Analysis** — product-level revenue, profit, margin and units
- **Region Analysis** — regional revenue, profit, orders and average order value
- **Data Dictionary** — field definitions and KPI logic

## Excel techniques demonstrated

- Structured data table
- Formula-driven revenue, COGS, gross profit and margin
- `SUMIFS`, `COUNTIFS`, `IF`, `IFERROR`, `YEAR` and `TEXT`
- Conditional formatting
- KPI cards
- Column, bar and line charts
- Monthly, product and regional analysis
- Business-focused dashboard layout
